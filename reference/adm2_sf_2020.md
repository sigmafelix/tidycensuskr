# South Korea Census Boundary in 2020

District level boundary data in 2020, repaired using 2015 historical
adjacency evidence and 2020 geometry only. Original attributes and row
order are retained. Polygon overlaps are removed and the
Guro/Yeongdeungpo/Dongjak/Gwanak junction is one shared point. Eight
unresolved historical reference pairs and two historically unconfirmed
contacts remain documented for review.

## Usage

``` r
adm2_sf_2020
```

## Format

An sf object with 250 rows and three fields: `year`, `adm2_code`, and
`geometry`. Coordinates use EPSG:5179.

## Source

Statistical Geographic Information Service (SGIS).

## Details

Validated 2010, 2015 and 2025 boundaries are registered datasets in the
companion `tidycensuskr.sf` package;
[`load_districts()`](https://sigmafelix.github.io/tidycensuskr/reference/load_districts.md)
selects their package automatically. Codes can be used to join
[`anycensus()`](https://sigmafelix.github.io/tidycensuskr/reference/anycensus.md)
output.
