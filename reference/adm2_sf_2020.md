# South Korea Census Boundary in 2020

District level boundary data in South Korea in 2020. `adm2_code` column
can be used to join with an
[`anycensus()`](https://sigmafelix.github.io/tidycensuskr/reference/anycensus.md)
output.

## Usage

``` r
adm2_sf_2020
```

## Format

A sf object with 250 rows and 3 variables:

## Source

- Statistical Geographic Information Service (SGIS)

## Details

- year Year of the census data, e.g., 2010, 2015, or 2020

- adm2_code Code of the district/municipal-level (Si-Gun-Gu)
  administrative unit

- geometry Geometry list-column
